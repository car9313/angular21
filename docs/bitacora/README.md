# Bitácora mensual

Archivo histórico del `docs/PLAN-DIARIO.md`.

## Convención

- Al cerrar el mes, mover el contenido del plan diario a `YYYY-MM.md` (por ejemplo `2026-10.md`).
- En `PLAN-DIARIO.md` queda solo el día actual.
- La bitácora es histórica: **no** es fuente de verdad del estado actual. Para eso están `ESTADO-DEL-PROYECTO.md`, `docs/MEMORIA-PROYECTO.md` y `docs/tareas-pendientes.md`.
- No editar meses cerrados salvo para corregir un dato factual, dejando la fecha de la corrección.
